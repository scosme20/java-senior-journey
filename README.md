# Java Senior Journey

Roadmap de estudo para evoluir de Java fundamental até engenharia sênior, com exercícios em código ao longo dos módulos.

**Status atual:** M1 e M2 em andamento.

## 🗺️ Roadmap

| Módulo | Tópicos | Status |
| --- | --- | --- |
| M1 — Fundamentos Profundos de Java | Java Moderno, OOP, Collections, Streams, Generics, Exceptions | ⏳ Em andamento |
| M2 — Estruturas de Dados e Algoritmos | Big O, Árvores, Grafos, Hash Tables, Algoritmos clássicos | ⏳ Em andamento |
| M3 — Engenharia de Código | SOLID, Clean Code, Refatoração, DDD Tactical | 🔒 Planejado |
| M4 — Design Patterns | Factory, Builder, Strategy, Observer, Proxy, Command | 🔒 Planejado |
| M5 — Spring Framework | Spring Boot, Spring MVC, Spring Security, Spring Data JPA | 🔒 Planejado |
| M6 — Banco de Dados | PostgreSQL, Redis, MongoDB, Query Optimization | 🔒 Planejado |
| M7 — Arquitetura de Software | Clean Architecture, Hexagonal Architecture, DDD, CQRS, Event Sourcing | 🔒 Planejado |
| M8 — Sistemas Distribuídos | Kafka, RabbitMQ, Saga Pattern, Circuit Breaker | 🔒 Planejado |
| M9 — Performance e Concorrência | Threads, Virtual Threads, JVM Internals, Garbage Collectors | 🔒 Planejado |
| M10 — DevOps | Docker, Kubernetes, Terraform, GitHub Actions | 🔒 Planejado |
| M11 — Cloud | AWS, EC2, S3, Lambda, EKS | 🔒 Planejado |
| M12 — Engenharia Senior | Observabilidade, OpenTelemetry, System Design, Leadership | 🔒 Planejado |
| M13 — Computer Science | Sistemas Operacionais, Redes, Compiladores, Distributed Systems, JVM Internals | 🔒 Planejado |
